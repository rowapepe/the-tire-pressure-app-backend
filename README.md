# Типы шин - Лабораторная работа №3 - REST API

## HTTP методы

Текущий пользователь задан константой и возвращается функцией-singleton `getCurrentUser()` (`src/common/current-user.ts`, `id = 1`). Функция используется во всех методах услуг.

### Домен услуг — `/api/tire_types`

| Метод  | URL                           | Описание                                                                     | Тело / параметры                                                                                                                   | Ответ                                                                                                                |
| ------ | ----------------------------- | ---------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| GET    | `/api/tire_types`             | Список опубликованных услуг с фильтрацией по радиусу                         | query: `radiusMin`, `radiusMax` (целые 13–22, необязательные)                                                                      | `200` массив услуг; `400` — неверный фильтр или `radiusMin > radiusMax`                                              |
| GET    | `/api/tire_types/feed`        | Лента без id — первая опубликованная услуга                                  | —                                                                                                                                  | `200` услуга; `404` — опубликованных нет                                                                             |
| GET    | `/api/tire_types/feed/:id`    | Лента по id; с `?next=true` — следующая опубликованная после `id` (по кругу) | query: `next` (`true`/`false`)                                                                                                     | `200` услуга; `404` — `id` не опубликована                                                                           |
| GET    | `/api/tire_types/draft`       | Черновик текущего пользователя (id не указывается)                           | —                                                                                                                                  | `200` услуга; `404` — черновика нет                                                                                  |
| POST   | `/api/tire_types`             | Создание черновика с файлами                                                 | `multipart/form-data`: `title` (1–100 символов), `image` (файл), `video` (файл)                                                    | `201` услуга со `status: draft`; `400` — нет файлов, неверный тип или размер, лишние поля; `409` — черновик уже есть |
| PUT    | `/api/tire_types/:id/publish` | Публикация черновика (`draft → published`)                                   | JSON: `description` (1–500), `optimalPressure` (0.5–9.9, один знак после запятой), `radius` (целое 13–22), `title` (необязательно) | `200` услуга; `400` — валидация; `404` — не найдена или чужая; `409` — уже не черновик                               |
| DELETE | `/api/tire_types/:id`         | Мягкое удаление своей услуги (`→ deleted`)                                   | —                                                                                                                                  | `200` `{message, status, timestamp}`; `404` — не найдена, чужая или уже удалена                                      |
| POST   | `/api/tire_types/:id/like`    | Поставить или снять лайк текущего пользователя                               | JSON: `like` — `1` ставит, `0` снимает                                                                                             | `200` `{likesCount, isLiked}`; `400` — `like` не 0/1; `404` — услуга не опубликована                                 |

### Домен пользователей — `/api/users`

| Метод | URL                   | Описание                                      | Тело                                                                               | Ответ                                                                  |
| ----- | --------------------- | --------------------------------------------- | ---------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| POST  | `/api/users/register` | Регистрация                                   | JSON: `login` (3–50 символов: латиница, цифры, `_ . -`), `password` (6–72 символа) | `201` `{id, login, createdAt}`; `400` — валидация; `409` — логин занят |
| POST  | `/api/users/login`    | Аутентификация — заглушка для лабораторной №4 | JSON: `login`, `password`                                                          | `200` `{message}`                                                      |
| POST  | `/api/users/logout`   | Деавторизация — заглушка для лабораторной №4  | —                                                                                  | `200` `{message}`                                                      |

## Таблицы БД

### `users` — пользователи

| Поле            | Тип          | Ограничения               | Описание               |
| --------------- | ------------ | ------------------------- | ---------------------- |
| `id`            | serial       | PK                        | идентификатор          |
| `login`         | varchar(50)  | NOT NULL, UNIQUE          | логин                  |
| `password_hash` | varchar(255) | NULL                      | хэш пароля `salt:hash` |
| `created_at`    | timestamp    | NOT NULL, default `now()` | дата создания          |

### `tire_types` — услуги (типы шин)

| Поле               | Тип          | Ограничения                                                  | Описание                                 |
| ------------------ | ------------ | ------------------------------------------------------------ | ---------------------------------------- |
| `id`               | serial       | PK                                                           | идентификатор                            |
| `title`            | varchar(100) | NOT NULL                                                     | наименование                             |
| `description`      | varchar(500) | NULL                                                         | краткое описание                         |
| `status`           | varchar(20)  | NOT NULL, default `'draft'`, CHECK `draft/published/deleted` | статус                                   |
| `image_name`       | varchar(255) | NULL                                                         | имя файла изображения в MinIO            |
| `video_name`       | varchar(255) | NULL                                                         | имя файла видео в MinIO                  |
| `optimal_pressure` | numeric(3,1) | NULL                                                         | оптимальное давление, бар (поле по теме) |
| `radius`           | smallint     | NULL                                                         | радиус колеса, дюймы (поле по теме)      |
| `created_at`       | timestamp    | NOT NULL, default `now()`                                    | дата создания                            |
| `formed_at`        | timestamp    | NULL                                                         | дата формирования (публикации)           |
| `creator_id`       | integer      | NOT NULL, FK → `users.id`, ON DELETE RESTRICT                | создатель                                |

### `tire_type_likes` — лайки (связь многие-ко-многим пользователь–услуга)

| Поле           | Тип     | Ограничения                                        | Описание          |
| -------------- | ------- | -------------------------------------------------- | ----------------- |
| `id`           | serial  | PK                                                 | идентификатор     |
| `user_id`      | integer | NOT NULL, FK → `users.id`, ON DELETE RESTRICT      | кто поставил лайк |
| `tire_type_id` | integer | NOT NULL, FK → `tire_types.id`, ON DELETE RESTRICT | какой услуге      |

Ограничение `UNIQUE (user_id, tire_type_id)` — один лайк на пару. Каскадного удаления нет.
